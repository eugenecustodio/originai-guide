How real-originai.com works

OriginAI takes a video of a person, from a file or a social media link, and returns how likely it is that the face was swapped or altered by AI. This guide follows that video through the website, the API and the GPU, and every explanation has a Code button that opens the exact lines in the repositories.

1. The page

The Scan page (frontend/pages/new-scanner.html, run by frontend/js/scanner.js) checks the video, uploads it, and shows the result.

2. The server

One FastAPI program on Render (backend/server.py) serves the pages and the API, checks every video, and keeps the line for the GPU.

3. The GPU

A rented RTX 5090 on Vast.ai runs the detectors (originai-vast/model_server) and sends back the scores and evidence pictures.

The big picture

Architecture: who talks to whom

The browser only ever talks to the web server on Render. The web server is the only part that talks to Vast.ai, because every Vast call needs the account's API key. Click a box to see what it does and its code.

  • Cost: the GPU is billed per second only while it runs; the web server is free. Videos are checked on the free server first, so a bad file never costs GPU time.
  • Security: the Vast key stays on Render and the Backblaze key on Vast; the browser holds neither.
  • Scaling: the server's line feeds the GPU 3 scans at a time, and Vast stops the GPU when nobody scans.

Step by step

The life of one scan

Follow a video from the visitor's click to the result. Choose a file upload or a link, then step through; the diagram lights up the part that is working, and each step shows its code.

Statuses

Job stages: what the API reports

A check moves through at most four stages, fetching, queued, analyzing and completed, and can end early as refused, canceled or failed. Uploads skip fetching. Cancel works only before the GPU has the video. Click a stage.

For programs

The API

The API is the same FastAPI program that serves the pages; the Scan page is just one client. It is free and needs no key. Because a GPU check takes seconds to minutes, it works as a job you check on: start it, get an id at once (202), then ask for it until it is done.

Every endpoint is a decorated function in backend/server.py: the decorator (@app.get, @app.post, @app.api_route) names the address and method. Pick one to see its real answer and its code. Answers marked live, October 18 were fetched from the site; the others were recorded from real scans on October 9, 2026.

Errors

Every error is JSON {"detail": "<sentence for the visitor>", "code": "<code>"} . A check that fails on the GPU still answers 200 for the job, with status: "failed", a reason and an error sentence.

Links, through yt-dlp

  1. Accept the link safely. Only hosts of a switched-on platform; no IP addresses, usernames in links or odd ports.
  2. Follow share links. One hop at a time, each kept on the platform.
  3. Look it up. yt-dlp reads title, length and quality without downloading; only the platform's own extractors may run.
  4. Download. The sharpest version from 360p to 1080p, H.264/H.265 first, into backend/outputs/vast_uploads/; stopped past 250 MB; checked with PyAV.
  5. Explain failures. yt-dlp's errors become codes such as private, blocked or fetch_failed.

On the GPU

The detection pipeline

Every video goes through the thesis's frozen preprocessing (preprocessing_v001), then every face frame is scored in clips at the spacing the model was trained on. Click a step for its code. The whole run is one function .

Try it: interleaved phases

The model reads 16 frames spaced as in training (0.34 s for Veni, 0.345 s for Vici, 0.33 s with 10-frame clips for Vidi). To still use every frame, the video is split into k interleaved phases, k = round(spacing × fps), using Python's rounding .

The decision

p = sigmoid( mean(clip logits) / T )   →   Likely Deepfake if p ≥ threshold

T (temperature) and the threshold come from each model's validation run: temperature scaling, then the threshold that maximizes Youden's J.

Up to 3 scans share the GPU at once; one that runs out of memory is re-run alone.

Picking a detector

Auto

Auto measures a few frames and asks six questions in order; the first "yes" picks the detector. It never picks Veni HQ, because a clean video can't show whether a fake is a polished one. The cut-offs are hand-set and were not evaluated in the study. Move the sliders to see what it would pick.

The same rules exist twice and must stay equal: on the server and in the page . The page measures files it can play; the server measures links and files the browser can't read .

Running it

Hosting and deploys

A code change goes live by pushing to GitHub; nothing is copied to a server by hand. Render rebuilds the site, obfuscates the page scripts, checks its health and switches over in about 2 minutes.

Serving the site and the obfuscation build

Render sets ORIGINAI_FRONTEND_DIR=../frontend-dist, so the server serves the built copy and never the readable frontend/ . The build obfuscates page scripts, minifies CSS and HTML, leaves out internal notes, and versions every link with a content hash . Caching and security headers are set on every response .

The GPU side

Endpoint originai-detectors holds the scaling rules (min_load 0 = no GPU when idle; 100 = one always on, about $12 a day). The worker group says which machines may be rented; the template says which image runs. A new machine downloads a 3.4 GB image and about 2.3 GB of weights before it can scan: a cold start of 15 to 30 minutes.

Keeping it safe

Limits and safety

  • The line: 3 scans on the GPU, up to 50 waiting; beyond that busy (429).
  • Link requests: 300 per visitor every 10 minutes.
  • Size caps checked from the request header before reading: 251 MB for uploads, 64 KB for JSON.
  • Strict file names: uploads, jobs, pictures and pages must match exact patterns, so no request reaches another file.
  • The visitor's address is the third entry from the right of X-Forwarded-For on Render; a forged entry is ignored.
  • No CORS: other websites can't call the API from a visitor's browser.
  • Link safety: platform hosts only, every redirect re-checked, yt-dlp limited to the platform's extractors.
  • Short-lived files: uploads deleted when the check ends; results after one hour.

Words

Glossary

Deepfake
A real person's face that AI has swapped or altered. Fully generated video and cloned voices are not included.
Logit
The model's raw score for a clip before it becomes a probability.
Temperature scaling
Dividing logits by T, fitted on validation videos, so scores match how often the model is right.
Threshold (the line)
The score at which the answer flips to Likely Deepfake.
Youden's J
True-positive rate minus false-positive rate; the threshold that maximizes it balances catching fakes against false alarms.
ROC-AUC
How well scores separate real from fake over every threshold: 1.0 perfect, 0.5 a coin toss.
False positive / negative
A real video called a deepfake / a deepfake called real.
Cross-dataset generalization
How a detector does on a collection it never learned from (AUC about 0.997 to 0.874 in the thesis).
Frame spacing, clip, phases
The time between frames the model reads; the frames scored together; the offset sequences that let every frame be scored at the trained spacing.
MTCNN, alignment, tracking
Finding the face and its landmarks; warping it to a standard template; following one person through the video.
Evidence map
Which face regions pushed the score up; for Veni HQ, Veni LQ and Vici it equals Grad-CAM at the last layer.
Asynchronous job, polling
Start a job, get an id at once, then ask for it until it is done.
Serverless GPU, cold start
A GPU rented only while work needs it; the wait while a new one is rented and loaded.
CORS, SSRF
The browser rule that stops other sites calling the API; tricking a server into fetching internal addresses (blocked for links).
Obfuscation
Rewriting the page scripts so they are hard to read; it deters copying but cannot make browser code secret.
yt-dlp, PyAV
The open-source tool that reads videos from links; Python bindings for FFmpeg that open and check videos.
